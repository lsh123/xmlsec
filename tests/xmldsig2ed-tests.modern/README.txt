XML-Digital-Signature 2nd Edition Test Vectors (Modernized)
==============================================================================

The files in this folder are the same documents as in
tests/xmldsig2ed-tests/
(https://www.w3.org/TR/xmldsig2ed-tests/), but re-signed with modern
algorithms and the key from tests/keys/ (instead of the original HMAC
key):

	- the deprecated HMAC-SHA1 SignatureMethod was replaced with
	  HMAC-SHA256 (http://www.w3.org/2001/04/xmldsig-more#hmac-sha256),
	- the discouraged SHA-1 DigestMethod was replaced with SHA-256
	  (http://www.w3.org/2001/04/xmlenc#sha256),
	- the HMAC key is the one from tests/keys/hmackey.bin (the ASCII
	  encoding of the word "secret").

The original pre-signed files were not consistently generated from the
original templates (for example, the transforms in the pre-signed
defCan-2.xml and defCan-3.xml files differ from the ones in the
templates and the pre-signed defCan-3.xml file did not verify at all),
so all the pre-signed files here were re-generated by signing the
templates with xmlsec1.

Every test has an unsigned template <name>.tmpl (with empty
<DigestValue/> and <SignatureValue/> elements that xmlsec1 fills in
when signing) and a matching pre-signed <name>.xml file (the original
suite only had .xml files for the xpointer tests).

Keys
----

	hmackey.bin (tests/keys/)
	-----------
	The HMAC key (the ASCII encoding of the word "secret") used by all
	the tests.  The KeyName of the defCan tests is "TeskKeyName-Hmac"
	(as in the original templates).

Contents of xmldsig2ed-tests.modern
===================================

	defCan-1.{xml,tmpl}
	-------------------
	Contains an enveloping HMAC-SHA256 signature over the
	c14n11/xml-base-input.xml file with an XPath transform.  The test
	checks the default canonicalization (C14N11) when the transforms
	list does not include a canonicalization transform.


	defCan-2.{xml,tmpl}
	-------------------
	Contains an enveloping HMAC-SHA256 signature over the
	c14n11/xml-base-input.xml file with the XPath, XSLT and XPath
	transforms.


	defCan-3.{xml,tmpl}
	-------------------
	Contains an enveloping HMAC-SHA256 signature over the
	c14n11/xml-base-input.xml file with the XPath, XSLT, XPath and
	XSLT transforms.  In the original suite the pre-signed file for
	this test did not match the template (different XPath and
	transforms order) and the test was disabled in testDSig.sh; here
	the template and the pre-signed file are consistent, so the test
	is enabled again.


	xpointer-{1..6}-SUN.{xml,tmpl}
	-----------------------------
	Contain documents that check the behaviour of tools with regards
	to comments when using scheme-based xpointers in the ds:Reference
	URI attribute.  The tests use the "xpointer(/)" and
	"xpointer(id(...))" xpointers as well as the fragment-only
	"#e1ID" URIs, with the C14N11 with comments transform and the
	enveloped signature transform (for the enveloped tests).


	c14n11/xml-base-input.xml
	------------------------
	The input document referenced by the defCan tests (a copy of the
	file from the original tests/xmldsig2ed-tests/c14n11/ folder).
